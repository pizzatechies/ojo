Can't reach the server

Check these:

  • The server is running (for a live test, the window that ran start is still open).
  • This phone is on the same Wi-Fi as the computer running it. Guest and office Wi-Fi often block this; try a phone hotspot.
  • The address is right, including the port number (for example :8000).
  • The computer's firewall allows connections to that port.
